⚙️ Pengaturan Database Online

Hubungkan aplikasi ke Firebase Realtime Database (gratis) agar nilai hasil ujian siswa dapat dilihat dari perangkat mana saja. Cukup diisi satu kali oleh guru.

📖 Cara Mendapatkan Kredensial Firebase:
  1. Buka console.firebase.google.com dan login dengan akun Google.
  2. Klik Add project → beri nama (mis. asts-ppkn) → Create project.
  3. Di menu kiri, pilih Build → Realtime Database → Create Database.
  4. Pilih lokasi server (mis. Singapore) → mulai dalam test mode.
  5. Buka Project Settings (ikon ⚙️) → scroll ke Your apps → klik ikon Web </>.
  6. Salin objek firebaseConfig yang muncul, isi field di bawah ini.
Wajib diakhiri tanpa garis miring ( / ) di belakangnya.
